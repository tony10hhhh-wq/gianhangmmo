GianHangMMO - huong dan trien khai
1. Giai nen ZIP, upload cac file va thu muc ben trong len GitHub (khong upload ZIP).
2. Render > New Web Service > chon repository.
3. Build Command: npm ci --include=dev && npm run build
4. Start Command: npm start
5. Instance Type: Free. Environment: VITE_AUTH_ENABLED=false (trang cong cu cong khai, khong dung dang nhap Grok).
6. Name: gianhangmmo (neu con trong).
Chay local Windows: npm ci --include=dev, npm run dev.
Da sua wrapper Vite cho Windows va giu preset node_server cua ban RAR.
Chua kiem thu build/deploy thuc te; neu loi can xem build log. Khong upload API key, .env, du lieu rieng tu.
